# Sagebrush Inferno

A wild west, Doom-style first-person shooter that runs in the browser. It's a single HTML file with no build step and no external assets: every texture, sprite, sound effect and the music are generated in code when the page loads.

**Play:** https://hotsauce5000.github.io/sagebrush-inferno/

## The story
The Reverend Ezra Cinderjaw dug a well behind his church on Devil's Mesa and struck something hotter than water. Now the dead ride with the living outlaws, hellhounds prowl Dry Creek, and the only law left is you and a six-shooter.

## Features
- Raycasting engine with textured walls, floors and ceilings, wrap-around skies, distance fog and sliding doors
- Third-person fly-around intro at the start of each level, ending in first person
- Three chapters: Dry Creek, Copper Hollow and Devil's Mesa
- Four weapons: six-shooter, scattergun, Gatling gun and dynamite
- Outlaws, skeleton gunslingers, hellhounds and a boss
- Status bar with a reactive cowboy face, automap, level stats and three difficulty levels

## Controls
| Key | Action |
|---|---|
| WASD | Move / strafe |
| Mouse | Aim (click the view to capture the mouse) |
| Left click / Ctrl | Shoot (hold to keep firing) |
| 1-4 / mouse wheel | Switch weapons |
| E / Space | Open doors, pull the exit lever |
| Shift | Sprint |
| Arrow keys | Turn and move without a mouse |
| Tab | Map |
| M / F / Esc | Music, fullscreen, pause |

Requires a keyboard and mouse.
